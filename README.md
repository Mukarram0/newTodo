# Redux Todo App

A responsive task-management application built with React and Redux Toolkit.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Centralized state management with Redux Toolkit
- Responsive user interface

## Tech Stack

- React
- Redux Toolkit
- React Redux
- Vite
- CSS3

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm

### Installation

```bash
git clone https://github.com/Mukarram0/newTodo.git
cd newTodo
npm install
npm run dev
```

Open the local URL shown in your terminal to use the application.

## Available Commands

```bash
npm run dev
```

Starts the development server.

```bash
npm run build
```

Creates a production build.

```bash
npm run preview
```

Previews the production build locally.

```bash
npm run lint
```

Checks the project for linting issues.
